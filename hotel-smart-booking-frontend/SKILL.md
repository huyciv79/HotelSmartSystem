Apple Design Language (Summary)
Philosophy
Content before decoration.
Simplicity over complexity.
Every element must have a purpose.
Remove visual noise.
Premium, calm, and effortless experience.
Design should feel invisible.
Layout
Large whitespace between sections (96–160px).
Wide breathing room around content.
Strict alignment.
Consistent spacing scale.
Max content width around 1200–1400px.
Never overcrowd the interface.
Typography
Typography is the primary visual hierarchy.
Prefer SF Pro Display / SF Pro Text (or Geist as fallback).
Large hero headings.
Short supporting copy.
Tight heading tracking.
Comfortable body line height.
Never rely on decorative text effects.
Colors

Primary palette:

White
Black
Neutral grays

Accent colors:

Only when meaningful.
Usually product colors.
Never oversaturate.

Avoid:

Rainbow palettes.
Heavy gradients.
Neon colors.
Components

Buttons:

Simple.
Rounded but not exaggerated.
Minimal border.
No unnecessary shadows.

Cards:

Clean surfaces.
Soft radius.
Light borders.
Plenty of internal spacing.

Navigation:

Thin.
Transparent or blurred.
Minimal visual weight.

Forms:

Spacious.
Clean labels.
Clear focus states.
Imagery

Images should dominate the experience.

Use:

Large product renders.
High-quality photography.
Soft lighting.
Neutral backgrounds.

Avoid:

Busy stock photos.
Decorative illustrations everywhere.
Motion

Animation should feel natural.

Use:

Fade.
Scale.
Blur transitions.
Smooth easing.
Scroll-linked reveals.
Slow timing.

Avoid:

Bounce.
Elastic.
Flashy effects.
Constant movement.
Interaction

Every interaction should feel:

Predictable.
Responsive.
Lightweight.

Hover effects:

Slight opacity.
Small elevation.
Gentle scaling.
Visual Hierarchy

Emphasize through:

Size.
Weight.
Position.
Whitespace.

Not through:

Bright colors.
Heavy shadows.
Large borders.
Icons

Use simple geometric icons.

Consistent stroke width.

Avoid decorative icon styles.

Copywriting

Short.

Specific.

Human.

Avoid marketing clichés.

Engineering
Semantic HTML.
Accessible components.
Responsive by default.
Reusable components.
Consistent design tokens.
CSS variables for colors and spacing.
Performance-first animations.
Animate only transform and opacity.
Overall Feeling

The interface should feel:

Calm
Premium
Precise
Effortless
Elegant
Confident
Timeless

Never:

Loud
Busy
Trendy for its own sake
Overdesigned
Gamified
